Trend Unpacked

Personvernerklæring

Sist oppdatert: 15. oktober 2026

Trend Unpacked («vi», «oss» eller «kanalen») er en automatisert innholdskanal på YouTube (@trendunpacked), driftet av Thomas Myklebust Soleng. Denne personvernerklæringen beskriver hvordan Google-kontodata behandles når kanalens egen opplastingstjeneste kobler seg til YouTube Data API via Google OAuth 2.0 for å administrere kanalens videoer.

Behandlingsansvarlig: Thomas Myklebust Soleng (mythso.no).

1. Hva tjenesten er

Trend Unpacked publiseres av en automatisert pipeline som finner og researcher aktuelle temaer, genererer narrasjon og bilder med AI-verktøy, og bygger og laster opp korte videoer til kanalens egen YouTube-kanal. Videoer som inneholder AI-generert narrasjon eller annet syntetisk innhold merkes som dette ved opplasting, i tråd med YouTubes retningslinjer for syntetisk/endret innhold. Det er ingen andre brukere av tjenesten enn kanaleieren selv.

2. Google-tilgang og omfang (OAuth)

Tjenesten bruker Googles OAuth 2.0 til å få et begrenset sett tilganger til YouTube Data API v3, utelukkende knyttet til kanalen Trend Unpacked (kanal-ID UCUYiIcxsKks1KcO-xivd-Lg). Tilgangen brukes kun til å:

  • laste opp nye videoer til kanalen,
  • sette tittel, beskrivelse, kategori og status (inkl. AI-innhold-merking) på egne opplastede videoer,
  • lese kanalens egen video- og statistikkdata (f.eks. visninger, abonnenter, publiserte videoer) for intern måling og kvalitetssikring.

Det hentes eller behandles aldri data fra andre YouTube-kanaler, andre Google-kontoer, eller andre brukeres personlige informasjon.

3. Lagring og sikkerhet

Google-tilgangstokenet (refresh token) lagres som en kryptert miljøvariabel i en dedikert, passordbeskyttet mikrotjeneste driftet av kanaleieren. Tokenet er ikke tilgjengelig for tredjeparter, og brukes kun av denne ene tjenesten til å kommunisere direkte med Googles egne API-er.

4. Deling av data

Vi selger, deler eller overfører aldri Google- eller YouTube-data til tredjeparter. All bruk er begrenset til drift av Trend Unpacked sin egen kanal, i tråd med Googles API Services User Data Policy, inkludert kravene til begrenset bruk («Limited Use»).

5. Dine rettigheter

Siden den eneste autoriserte brukeren av denne integrasjonen er kanaleieren selv, kan tilgangen når som helst trekkes tilbake via Googles kontoinnstillinger på myaccount.google.com/permissions.

6. Endringer i personvernerklæringen

Vi kan oppdatere denne personvernerklæringen fra tid til annen. Eventuelle endringer publiseres på denne siden med ny dato for siste oppdatering.
